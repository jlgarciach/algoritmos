# Recursos del libro de Algoritmos

- `images/`: fotografías e imágenes generales.
- `figures/`: diagramas, esquemas y figuras numeradas.
- `icons/`: iconos propios del curso.
- `cpp/`: programas y fragmentos de C++ reutilizables.
- `python/`: ejemplos en Python cuando correspondan.
- `pseudocode/`: algoritmos y pseudocódigo en archivos separados.
- `datasets/`: datos para ejercicios.
- `videos/`: recursos audiovisuales o enlaces documentados.
- `downloads/`: archivos que los estudiantes podrán descargar.

Los capítulos permanecen únicamente en `capitulos/`; los recursos no se mezclan con el contenido.
