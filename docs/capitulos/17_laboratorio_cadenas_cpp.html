19  Laboratorio: Cadenas en C++

Autor/a

20 Propósito del laboratorio

En este laboratorio construiremos un programa completo para profundizar en el manejo de variables de tipo string y, al mismo tiempo, reforzar conocimientos que ya hemos trabajado: variables, decisiones, ciclos, procedimientos, funciones y parámetros.

Trabajaremos con un dato que utilizamos todos los días: el nombre completo de una persona. A partir de él aprenderemos que una cadena no solamente se almacena o se muestra en pantalla; también podemos medirla, recorrerla carácter por carácter, contar sus palabras y transformarla.

Idea clave: una cadena está formada por caracteres. Al analizar esos caracteres podemos obtener nueva información y transformar el texto.

20.1 Objetivos de aprendizaje

Al finalizar el laboratorio, el estudiante será capaz de:

  • Declarar y utilizar variables de tipo string.
  • Leer nombres completos que contienen espacios.
  • Utilizar procedimientos y funciones dentro de un mismo programa.
  • Enviar información a funciones mediante parámetros por valor.
  • Determinar la longitud de una cadena.
  • Recorrer una cadena carácter por carácter.
  • Contar palabras dentro de una cadena.
  • Transformar los caracteres de un texto.
  • Integrar diferentes módulos dentro de una solución completa.

21 Antes de comenzar: vocales con acento y la letra ñ

Antes de trabajar con cadenas debemos resolver una duda frecuente: ¿cómo podemos mostrar correctamente en la consola las vocales con acento (á, é, í, ó, ú) y la letra ñ?

Cuando escribimos mensajes en español es normal utilizar caracteres como:

número, año, niño, información, opción, programación

En algunos entornos de Windows, estos caracteres pueden mostrarse incorrectamente en la consola si no se utiliza la codificación adecuada. Para trabajar con UTF-8 podemos agregar la librería windows.h y configurar la entrada y salida de la consola.

#include <iostream>
#include <windows.h>

using namespace std;

int main() {

    SetConsoleOutputCP(CP_UTF8);
    SetConsoleCP(CP_UTF8);

    cout << "Ingrese el número de niños: ";

    return 0;
}

Las instrucciones:

SetConsoleOutputCP(CP_UTF8);
SetConsoleCP(CP_UTF8);

indican a la consola de Windows que utilice UTF-8 para la salida y la entrada de texto. A partir de ese momento podemos escribir normalmente mensajes como:

cout << "Ingrese el año de nacimiento: ";
cout << "Número de niños: ";
cout << "Información registrada correctamente." << endl;

Importante: windows.h, SetConsoleOutputCP() y SetConsoleCP() son específicos de Windows. Si utiliza un compilador en Linux, macOS o un entorno en línea que ya trabaja con UTF-8, normalmente no necesita estas instrucciones y windows.h podría no estar disponible.

Buena práctica: guarde siempre sus archivos de código fuente utilizando codificación UTF-8. Esto permite escribir directamente á, é, í, ó, ú y ñ dentro de las cadenas de texto.

22 1. El problema

Construiremos un programa que solicite al usuario:

  • Su nombre completo.
  • Su año de nacimiento.

A partir de esos datos, el programa deberá mostrar:

  1. Edad aproximada en años.
  2. Cantidad de caracteres que contiene el nombre completo.
  3. Cantidad de palabras que forman el nombre.
  4. Nombre completo convertido a mayúsculas.
  5. Iniciales de la persona.

El programa deberá estar organizado mediante un procedimiento y varias funciones.

Importante: antes de consultar cada solución, intente construirla. El objetivo del laboratorio es analizar, diseñar y programar, no copiar código.

23 2. Diseñemos antes de programar

Dividamos el problema en tareas pequeñas.

Módulo Tipo Responsabilidad
Solicitar datos Procedimiento Solicitar nombre completo y año de nacimiento y mostrar los resultados
Calcular edad Función Obtener la edad aproximada a partir del año de nacimiento
Longitud del nombre Función Determinar la cantidad de caracteres
Contar palabras Función Determinar cuántas palabras forman el nombre
Convertir a mayúsculas Función Transformar el nombre completo a letras mayúsculas

Observe que cada módulo tiene una responsabilidad específica.

La idea es que la función principal únicamente inicie el programa y que el trabajo se distribuya entre el procedimiento y las funciones.

25 4. Paso 1: solicitar los datos

Nuestro primer módulo será un procedimiento encargado de coordinar el programa.

Dentro de este procedimiento debemos:

  1. Crear una variable para almacenar el nombre completo.
  2. Crear una variable para almacenar el año de nacimiento.
  3. Solicitar ambos datos al usuario.
  4. Conservarlos para enviarlos posteriormente a las diferentes funciones.

25.1 Un pequeño problema que debemos resolver

El nombre de una persona normalmente contiene espacios. Por ejemplo:

Maria Fernanda Lopez

Por lo tanto, debemos utilizar una forma de lectura que permita capturar toda la línea y no solamente la primera palabra.

Intente construir el procedimiento antes de consultar la solución.

Ver solución: procedimiento para solicitar datos 
void solicitarDatos() {
    string nombre;
    int anioNacimiento;

    cout << "Ingrese su nombre completo: ";
    getline(cin, nombre);

    cout << "Ingrese su anio de nacimiento: ";
    cin >> anioNacimiento;
}

Observe: utilizamos getline() porque necesitamos capturar el nombre completo, incluyendo los espacios.

26 5. Paso 2: calcular la edad

Construya una función que reciba como parámetro el año de nacimiento y devuelva la edad aproximada de la persona.

Para este laboratorio utilizaremos 2026 como año actual.

Por ejemplo:

Año de nacimiento: 2005
Edad aproximada: 21 años

Piense antes de programar:

  • ¿Qué dato recibe la función?
  • ¿Qué tipo de dato debe devolver?
  • ¿Qué operación matemática necesita realizar?
Ver solución: función para calcular la edad 
int calcularEdad(int anioNacimiento) {
    return 2026 - anioNacimiento;
}

Nota: la edad es aproximada porque solamente estamos utilizando el año de nacimiento. No conocemos el día ni el mes.

27 6. Paso 3: obtener la longitud del nombre

Ahora construiremos una función que reciba el nombre completo y devuelva la cantidad total de caracteres que contiene.

Recuerde que los espacios también forman parte de una cadena y, por lo tanto, cuentan como caracteres.

Por ejemplo:

Ana Lopez

contiene 9 caracteres.

Antes de consultar la solución, determine mentalmente:

Cadena Cantidad de caracteres
Luis ?
Ana Maria ?
Juan Perez ?
Ver respuestas y solución
Cadena Cantidad de caracteres
Luis 4
Ana Maria 9
Juan Perez 10

La función puede construirse así:

int longitudNombre(string nombre) {
    return nombre.length();
}

El método .length() devuelve la cantidad de caracteres almacenados en la cadena.

28 7. Paso 4: contar las palabras del nombre

Ahora tenemos un problema más interesante.

Observe el siguiente nombre:

Jorge Luis Garcia Chacon

Visualmente podemos determinar que contiene cuatro palabras. Sin embargo, nuestro programa debe descubrirlo automáticamente.

Construya una función que:

  1. Reciba el nombre completo.
  2. Recorra sus caracteres uno por uno.
  3. Detecte cuándo comienza una nueva palabra.
  4. Lleve un contador.
  5. Devuelva la cantidad total de palabras encontradas.

28.0.1 Antes de programar

Analice estas entradas:

Carlos
Ana Maria
Juan Carlos Perez

¿Cuántas palabras debería devolver la función en cada caso?

Piense cómo podría utilizar los espacios para detectar dónde termina o comienza una palabra.

Ver solución: función para contar palabras 
int contarPalabras(string texto) {
    int palabras = 0;
    bool dentroPalabra = false;

    for (int i = 0; i < texto.length(); i++) {
        if (texto[i] != ' ' && dentroPalabra == false) {
            palabras++;
            dentroPalabra = true;
        }
        else if (texto[i] == ' ') {
            dentroPalabra = false;
        }
    }

    return palabras;
}

En esta solución estamos integrando varios conocimientos anteriores: variables, bool, ciclos, decisiones, operadores, parámetros y retorno de valores.

29 8. Paso 5: convertir el nombre a mayúsculas

Construya una función que reciba el nombre completo y devuelva una nueva cadena con todas sus letras en mayúscula.

Ejemplo:

Entrada : Jorge Luis Garcia
Salida  : JORGE LUIS GARCIA

Para resolverlo deberá pensar en algo importante:

Si queremos transformar todo el nombre, tendremos que recorrer todos sus caracteres.

La función deberá devolver un string.

Ver solución: convertir a mayúsculas 
string convertirMayusculas(string texto) {
    for (int i = 0; i < texto.length(); i++) {
        texto[i] = toupper(texto[i]);
    }

    return texto;
}

toupper() transforma un carácter a mayúscula. Al combinarla con un ciclo podemos transformar la cadena completa.

30 9. Paso 6: obtener las iniciales

Construiremos ahora una función que transforme:

Jorge Luis Garcia Chacon

en:

JLGC

La función deberá:

  1. Recibir el nombre completo.
  2. Identificar la primera letra de cada palabra.
  3. Convertir cada inicial a mayúscula.
  4. Construir una nueva cadena con las iniciales encontradas.
  5. Devolver el resultado.

30.0.1 Pista de análisis

No piense todavía en instrucciones de C++. Piense primero en cómo lo haría una persona:

  • La primera letra del nombre es una inicial.
  • Después de un espacio comienza otra palabra.
  • La primera letra de esa nueva palabra también es una inicial.

Ahora intente convertir esa lógica en un algoritmo.

Ver solución: obtener iniciales 
string obtenerIniciales(string nombre) {
    string iniciales = "";

    if (nombre.length() > 0) {
        iniciales += toupper(nombre[0]);
    }

    for (int i = 1; i < nombre.length(); i++) {
        if (nombre[i - 1] == ' ' && nombre[i] != ' ') {
            iniciales += toupper(nombre[i]);
        }
    }

    return iniciales;
}

Ya tenemos las piezas principales. Ahora debemos regresar al procedimiento que solicita los datos.

La condición es importante:

Ver solución: procedimiento integrado 
void solicitarDatos() {

32 11. Construya la función principal

Llegó el momento de crear la función principal del programa.

Como hemos distribuido las responsabilidades correctamente, la función principal debe ser muy sencilla: solamente necesita iniciar el procedimiento que coordina nuestro programa.

35 14. Un desafío adicional: corregir el formato del nombre

Ahora aumentaremos un poco la dificultad.

Queremos construir una nueva función capaz de transformar:

jORGE lUIS garCIA

en:

Jorge Luis Garcia

La regla será:

  • La primera letra de cada palabra debe quedar en mayúscula.
  • Las demás letras deben quedar en minúscula.
  • Los espacios deben conservarse.

Antes de programar, responda:

  1. ¿Cómo podemos reconocer que estamos al inicio de una palabra?
  2. ¿Qué debemos hacer cuando encontramos un espacio?
  3. ¿Será necesario recorrer toda la cadena?
  4. ¿Qué deberá devolver la función?

Intente construirla y agréguela al programa.

Ver solución: formato correcto del nombre 
string formatoNombre(string texto) {
    bool nuevaPalabra = true;

    for (int i = 0; i < texto.length(); i++) {
        if (texto[i] == ' ') {
            nuevaPalabra = true;
        }
        else if (nuevaPalabra == true) {
            texto[i] = toupper(texto[i]);
            nuevaPalabra = false;
        }
        else {
            texto[i] = tolower(texto[i]);
        }
    }

    return texto;
}

36.1 Condiciones

  • Cada operación debe resolverse mediante una función diferente.
  • Las funciones deben recibir el nombre mediante un parámetro.
  • No se permite colocar toda la solución directamente dentro de la función principal.
  • Debe utilizar al menos un ciclo en una de las funciones nuevas.
  • Los resultados deben integrarse a la salida general del programa.
