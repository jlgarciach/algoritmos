15  Matrices y arreglos multidimensionales en C++

De los vectores paralelos a la organización de datos en filas y columnas

Autor/a

Ing. Jorge L. García

Fecha de publicación

7 de septiembre de 2026

16 Antes de comenzar

En la clase anterior aprendimos que varios vectores pueden trabajar de forma paralela.

Por ejemplo, podemos tener:

string carnet[35];
string nombre[35];
float nota[35];

Si utilizamos la misma posición en los tres arreglos, los datos están relacionados:

Posición       carnet          nombre           nota
   0           2026001         Ana               85
   1           2026002         Carlos            62
   2           2026003         María             94

Así:

nombre[2]

y:

nota[2]

pertenecen al mismo estudiante.

TipIdea importante

Un vector nos permite organizar una lista de elementos.

Pero, ¿qué sucede cuando necesitamos organizar información utilizando filas y columnas?

17 El nuevo requerimiento

Supongamos que ahora necesitamos almacenar las notas de varios cursos.

Podríamos crear:

float algoritmos[35];
float matematica[35];
float fisica[35];

Esto funciona.

Pero imaginemos que posteriormente necesitamos 5, 10 o incluso 20 cursos.

Tendríamos que crear cada vez más vectores.

float algoritmos[35];
float matematica[35];
float fisica[35];
float estadistica[35];
float programacion[35];
// ...

Entonces aparece una pregunta:

¿Existe una forma de organizar todas las notas utilizando una sola estructura?

Sí.

Podemos utilizar una matriz.

18 Pensemos primero en Excel

Antes de escribir código, pensemos en una hoja de cálculo.

Una tabla de calificaciones podría verse así:

Estudiante Algoritmos Matemática Física
Ana 85 78 90
Carlos 62 71 68
María 94 89 92
José 71 65 77

¿Qué observamos?

  • Cada fila representa un estudiante.
  • Cada columna representa un curso.
  • Cada celda contiene una nota.
  • Para localizar una nota necesitamos saber dos posiciones: fila y columna.

Por ejemplo, si numeramos desde cero:

Columna 0 Columna 1 Columna 2
Fila 0 85 78 90
Fila 1 62 71 68
Fila 2 94 89 92
Fila 3 71 65 77

La nota 89 está ubicada en:

fila = 2
columna = 1

En C++ podríamos acceder a ella mediante:

notas[2][1]
NotaEl cambio fundamental

En un vector utilizábamos un índice:

nota[i]

En una matriz utilizaremos dos índices:

nota[i][j]

El primero identifica la fila y el segundo la columna.

19 ¿Qué es una matriz?

Una matriz es un arreglo bidimensional que organiza elementos del mismo tipo en filas y columnas.

Por ejemplo:

int matriz[3][3];

crea una estructura de:

  • 3 filas
  • 3 columnas
  • 9 posiciones en total

Podemos imaginarla así:

          columnas
           0   1   2
         +---+---+---+
fila 0   |   |   |   |
         +---+---+---+
fila 1   |   |   |   |
         +---+---+---+
fila 2   |   |   |   |
         +---+---+---+

Cada elemento tiene una posición formada por dos índices:

matriz[fila][columna]

20 Comparación con un vector

Un vector:

int numeros[5];

puede visualizarse como:

[ 10 ][ 20 ][ 30 ][ 40 ][ 50 ]
   0     1     2     3     4

Para obtener 30 utilizamos:

numeros[2]

Una matriz:

int numeros[3][3];

puede visualizarse como:

        0    1    2
      +----+----+----+
  0   |  5 |  8 |  6 |
      +----+----+----+
  1   |  7 |  9 |  4 |
      +----+----+----+
  2   |  3 |  2 |  1 |
      +----+----+----+

Para obtener el valor 9 utilizamos:

numeros[1][1]

Porque está en la fila 1 y columna 1.

21 Recordemos: los índices comienzan en cero

Una matriz de:

int matriz[3][3];

tiene índices válidos:

Filas:     0, 1, 2
Columnas:  0, 1, 2

Por lo tanto:

matriz[0][0]

es la primera posición.

Mientras que:

matriz[2][2]

es la última.

AdvertenciaCuidado

En una matriz 3 x 3 no existe:

matriz[3][3]

porque los índices comienzan en cero.

22 Inicialización de una matriz

Al igual que con los arreglos que ya conocemos, podemos asignar valores desde la declaración.

int matriz[3][3] = {
    {5, 8, 6},
    {7, 9, 4},
    {3, 2, 1}
};

Cada grupo representa una fila.

{5, 8, 6}  -> fila 0
{7, 9, 4}  -> fila 1
{3, 2, 1}  -> fila 2

También podemos modificar una posición individual:

matriz[1][2] = 10;

23 ¿Cómo llenamos una matriz con datos del usuario?

Con un vector utilizábamos un ciclo:

for (int i = 0; i < 5; i++) {
    cin >> notas[i];
}

Pero ahora necesitamos recorrer filas y columnas.

Por eso utilizamos dos ciclos.

for (int i = 0; i < 3; i++) {

    for (int j = 0; j < 3; j++) {

        cin >> matriz[i][j];

    }
}

Podemos interpretarlo así:

i = controla las filas
j = controla las columnas

El ciclo exterior selecciona una fila.

El ciclo interior recorre todas las columnas de esa fila.

24 Sigamos el recorrido paso a paso

Para una matriz 2 x 3:

int tabla[2][3];

el recorrido será:

i = 0, j = 0   -> tabla[0][0]
i = 0, j = 1   -> tabla[0][1]
i = 0, j = 2   -> tabla[0][2]

i = 1, j = 0   -> tabla[1][0]
i = 1, j = 1   -> tabla[1][1]
i = 1, j = 2   -> tabla[1][2]

Observe que primero se recorren todas las columnas de la fila 0.

Después se pasa a la fila 1.

TipRelación con lo que ya sabemos

No estamos aprendiendo un ciclo nuevo.

Seguimos utilizando for.

La diferencia es que ahora un ciclo está dentro de otro, porque necesitamos controlar dos dimensiones.

25 Mostrar una matriz como una tabla

Podemos mostrarla conservando visualmente las filas y columnas:

for (int i = 0; i < 3; i++) {

    for (int j = 0; j < 3; j++) {
        cout << matriz[i][j] << "\t";
    }

    cout << endl;
}

Si los valores son:

int matriz[3][3] = {
    {5, 8, 6},
    {7, 9, 4},
    {3, 2, 1}
};

obtendremos:

5       8       6
7       9       4
3       2       1

26 Caso de la vida real: registro de calificaciones

Retomemos el problema con el que terminamos vectores.

Tenemos estudiantes y ahora necesitamos almacenar las notas de tres cursos.

Podemos conservar información como el nombre en un vector:

string nombres[3] = {"Ana", "Carlos", "Maria"};

Y utilizar una matriz para las notas:

float notas[3][3] = {
    {85, 70, 66},
    {77, 40, 91},
    {60, 100, 89}
};

Podemos interpretar la matriz así:

Alumno Algoritmos Contabilidad Otro curso
Ana 85 70 66
Carlos 77 40 91
María 60 100 89

Observe algo importante:

nombres[1]

representa a Carlos.

Y:

notas[1][0]
notas[1][1]
notas[1][2]

son las tres notas de Carlos.

La fila 1 de la matriz está relacionada con la posición 1 del vector de nombres.

27 Ejemplo 1: promedio por estudiante

Queremos calcular el promedio de cada alumno.

Para cada fila debemos sumar sus columnas.

#include <iostream>
#include <string>
using namespace std;

int main() {

    const int ALUMNOS = 3;
    const int CURSOS = 3;

    string nombres[ALUMNOS] = {
        "Ana",
        "Carlos",
        "Maria"
    };

    float notas[ALUMNOS][CURSOS] = {
        {85, 70, 66},
        {77, 40, 91},
        {60, 100, 89}
    };

    for (int i = 0; i < ALUMNOS; i++) {

        float suma = 0;

        for (int j = 0; j < CURSOS; j++) {
            suma += notas[i][j];
        }

        float promedio = suma / CURSOS;

        cout << nombres[i]
             << " - Promedio: "
             << promedio << endl;
    }

    return 0;
}

Observe dónde se coloca:

float suma = 0;

Debe reiniciarse para cada estudiante.

28 Pensemos antes de continuar

Para la siguiente matriz:

int datos[4][5];

responda:

  1. ¿Cuántas filas tiene?
  2. ¿Cuántas columnas tiene?
  3. ¿Cuántos elementos puede almacenar?
  4. ¿Cuál es la primera posición?
  5. ¿Cuál es la última posición?
NotaRespuesta
  • Filas: 4
  • Columnas: 5
  • Elementos: 20
  • Primera posición: datos[0][0]
  • Última posición: datos[3][4]

29 Comparación: arreglo, vector y matriz

Estructura Organización Tamaño Acceso
Arreglo Una dimensión Fijo datos[i]
vector de C++ Una dimensión Puede cambiar datos[i]
Matriz tradicional Dos dimensiones Fijo datos[i][j]

Todos permiten almacenar elementos del mismo tipo.

La matriz puede entenderse como una extensión natural de los arreglos: ahora organizamos los elementos utilizando más de una dimensión.

30 Ejercicio guiado

Construya un programa que permita ingresar una matriz de 3 x 3.

Después deberá calcular:

  • suma de todos los elementos;
  • promedio de todos los elementos;
  • valor máximo;
  • valor mínimo.

Antes de programar, responda:

¿Cuántas veces tendremos que visitar cada posición de la matriz?

La respuesta es importante: para realizar estos cálculos basta con recorrer cada posición una vez.

30.1 Paso 1: declarar la matriz

const int FILAS = 3;
const int COLUMNAS = 3;

int matriz[FILAS][COLUMNAS];

30.2 Paso 2: ingresar los datos

for (int i = 0; i < FILAS; i++) {

    for (int j = 0; j < COLUMNAS; j++) {

        cout << "Ingrese [" << i << "][" << j << "]: ";
        cin >> matriz[i][j];

    }
}

30.3 Paso 3: procesar los datos

int suma = 0;
int mayor = matriz[0][0];
int menor = matriz[0][0];

for (int i = 0; i < FILAS; i++) {

    for (int j = 0; j < COLUMNAS; j++) {

        suma += matriz[i][j];

        if (matriz[i][j] > mayor) {
            mayor = matriz[i][j];
        }

        if (matriz[i][j] < menor) {
            menor = matriz[i][j];
        }
    }
}

30.4 Paso 4: calcular el promedio

float promedio = (float)suma / (FILAS * COLUMNAS);

30.5 Paso 5: mostrar resultados

cout << "Suma: " << suma << endl;
cout << "Promedio: " << promedio << endl;
cout << "Mayor: " << mayor << endl;
cout << "Menor: " << menor << endl;

31 Buenas prácticas

Cuando trabajemos con matrices procuraremos:

  • utilizar constantes para definir tamaños;
  • utilizar nombres que indiquen qué representa cada dimensión;
  • validar los datos ingresados cuando el problema lo requiera;
  • presentar los resultados en forma de tabla cuando sea posible;
  • evitar números escritos repetidamente dentro de los ciclos.

En lugar de:

int notas[35][5];

podemos utilizar:

const int ALUMNOS = 35;
const int CURSOS = 5;

int notas[ALUMNOS][CURSOS];

Así el código explica mejor lo que representa cada dimensión.

32 Más de dos dimensiones

Una matriz bidimensional utiliza:

datos[fila][columna]

Pero C++ también permite arreglos de más dimensiones.

Por ejemplo:

int datos[3][3][3];

En este caso necesitamos tres índices:

datos[i][j][k]

Un ejemplo puede ser la representación de información que depende de tres coordenadas o dimensiones, como ciertos mapas, simulaciones o videojuegos.

AdvertenciaPor ahora…

No necesitamos complicarnos con arreglos de tres o más dimensiones.

Primero debemos dominar completamente:

matriz[i][j]

y el uso de ciclos anidados.

33 Comprobemos la comprensión

Sin ejecutar código, observe:

int matriz[2][4] = {
    {10, 20, 30, 40},
    {50, 60, 70, 80}
};

Responda:

  1. ¿Qué valor contiene matriz[0][2]?
  2. ¿Qué valor contiene matriz[1][0]?
  3. ¿En qué posición se encuentra el valor 80?
  4. ¿Cuántos elementos tiene la matriz?
  5. ¿Qué sucede conceptualmente si intercambiamos los índices?
NotaRespuestas
  1. 30
  2. 50
  3. matriz[1][3]
  4. 8
  5. Cambiamos la fila por la columna; no estamos señalando necesariamente la misma posición.

34 El reto para el laboratorio

Ya sabemos representar:

               Curso 0   Curso 1   Curso 2
Estudiante 0      85        70        66
Estudiante 1      77        40        91
Estudiante 2      60       100        89

El siguiente paso será construir un programa que permita trabajar con una tabla de calificaciones de forma más completa.

En el laboratorio podremos incorporar operaciones como:

  • ingreso de datos;
  • promedio por estudiante;
  • promedio por curso;
  • estudiante con mejor promedio;
  • búsqueda y presentación de información.

Todo parte de una sola idea:

notas[estudiante][curso]

35 Cierre

En esta clase avanzamos desde una estructura de una dimensión hacia una estructura de dos dimensiones.

Variable
   ↓
Arreglo / Vector
   ↓
Vectores paralelos
   ↓
Necesidad de filas y columnas
   ↓
Matriz

Una matriz no aparece como un concepto aislado.

Es una solución natural cuando nuestros datos ya no pueden representarse cómodamente como una sola lista.

TipIdea para recordar

Vector: necesito una posición.

datos[i]

Matriz: necesito dos posiciones.

datos[i][j]

Primero ubicamos la fila. Después, la columna.
