12  Laboratorio: Modularización del analizador de notas

Funciones, procedimientos, parámetros y arreglos

13 1. El reto de hoy

En el laboratorio anterior construimos un programa capaz de:

  • registrar cinco notas;
  • almacenar las notas en un arreglo;
  • mostrar los valores registrados;
  • calcular el promedio;
  • encontrar la nota mayor;
  • encontrar la nota menor;
  • contar estudiantes aprobados;
  • contar estudiantes reprobados.

El programa funciona.

Ahora tenemos un nuevo reto:

No construiremos un programa nuevo. Aprenderemos a construir mejor un programa que ya sabemos resolver.

TipMeta del laboratorio

Reestructurar el Analizador de notas utilizando:

  • arreglos;
  • funciones;
  • procedimientos;
  • parámetros;
  • valores de retorno.

El resultado del programa deberá ser el mismo. Lo que cambiará será la organización del código.

14 2. Del programa completo a un programa modular

Hasta ahora hemos colocado gran parte de las instrucciones dentro de:

NotaNuestro punto de partida

Este programa ya funciona y resuelve correctamente el problema.

No vamos a cambiar lo que hace.

Nuestro objetivo será descubrir cómo podemos dividirlo en módulos más pequeños, utilizando procedimientos, funciones y parámetros.

📌 Ver programa completo del laboratorio anterior 
// código anterior...
#include <iostream>
using namespace std;

int main()
{
    // muchas instrucciones...
    const int TAM = 5;
    int notas[TAM];
    int suma = 0;
    double promedio;
    int aprobados = 0;
    int reprobados = 0;

    // Ingreso de las notas
    cout << "\n================================" << endl;
    cout << " RESULTADOS" << endl;
    cout << "================================" << endl;
    for (int i = 0; i < TAM; i++)
    {
        cout << "Ingrese nota [" << (1 + i) << "]: ";
        cin >> notas[i];
    }

    // Inicializamos mayor y menor con un valor real del arreglo
    int mayor = notas[0];
    int menor = notas[0];

    // Procesamiento
    for (int i = 0; i < TAM; i++)
    {
        suma = suma + notas[i];
        if (notas[i] > mayor) mayor = notas[i];
        if (notas[i] < menor) menor = notas[i];
        if (notas[i] >= 61) aprobados++;
        else reprobados++;
    }

    promedio = suma / static_cast<double>(TAM);
    // Mostrar las notas
    cout << "\n================================" << endl;
    cout << " NOTAS REGISTRADAS" << endl;
    cout << "================================" << endl;
    for (int i = 0; i < TAM; i++)
    {
        cout << "Indice " << (1+i)
             << " -> " << notas[i] << endl;
    }

    // Resultados
    cout << "\n================================" << endl;
    cout << " RESULTADOS" << endl;
    cout << "================================" << endl;
    cout << "Suma: " << suma << endl;
    cout << "Promedio: " << promedio << endl;
    cout << "Nota mayor: " << mayor << endl;
    cout << "Nota menor: " << menor << endl;
    cout << "Aprobados: " << aprobados << endl;
    cout << "Reprobados: " << reprobados << endl;
    
    return 0;
}

Pero si observamos nuestro programa, podemos identificar tareas diferentes:

Ingresar notas
Mostrar notas
Calcular promedio
Buscar mayor
Buscar menor
Contar aprobados
Contar reprobados
Mostrar resultados

Cada una de estas tareas puede convertirse en una parte independiente del programa.

A esto lo llamamos modularización.

NotaIdea central

Modularizar no significa cambiar el algoritmo.

Significa dividir un problema grande en tareas más pequeñas, de manera que el programa resulte más fácil de leer, comprender, probar y mantener.

15 3. La estructura que queremos alcanzar

Nuestro objetivo será transformar el programa anterior hasta conseguir que main() se parezca a la siguiente estructura:

int main()
{
    const int TAM = 5;
    int notas[TAM];

    double promedio;
    int mayor;
    int menor;
    int aprobados;
    int reprobados;

    ingresarNotas(notas, TAM);
    mostrarNotas(notas, TAM);

    promedio = calcularPromedio(notas, TAM);
    mayor = buscarMayor(notas, TAM);
    menor = buscarMenor(notas, TAM);
    aprobados = contarAprobados(notas, TAM);
    reprobados = contarReprobados(notas, TAM);

    mostrarResultados(promedio, mayor, menor,
                      aprobados, reprobados);

    return 0;
}
ImportanteObserva antes de programar

Todavía no sabemos cómo está construida cada función.

Eso es precisamente lo que desarrollaremos juntos.

Por ahora observa algo importante:

¿Puedes comprender qué hace el programa únicamente leyendo main()?

18 6. Procedimientos y funciones

Durante el laboratorio utilizaremos dos tipos de módulos.

18.1 Procedimiento

Realiza una tarea, pero no devuelve un valor mediante return.

Su tipo será:

void

18.2 Función

Realiza un proceso y devuelve un resultado.

Por ejemplo, conceptualmente:

calcular algo
        ↓
devolver resultado
        ↓
guardar resultado en una variable
TipPregunta para el grupo

Observa:

promedio = calcularPromedio(notas, TAM);

¿Por qué calcularPromedio() parece comportarse diferente de:

mostrarNotas(notas, TAM);

¿Qué está devolviendo una y qué está haciendo la otra?

19 7. ¿Qué información debe viajar entre los módulos?

Las variables principales serán declaradas dentro de main().

Por ejemplo:

const int TAM = 5;
int notas[TAM];

Estas variables son locales de main().

Para que otra función pueda trabajar con ellas, tendremos que enviar la información mediante parámetros.

Observa:

ingresarNotas(notas, TAM);

Aquí estamos enviando:

notas → arreglo con las notas
TAM   → cantidad de elementos
ImportanteRecuerda

Pasar una variable como parámetro no la convierte en una variable global.

La función recibe la información que necesita para realizar su tarea.

20 8. Plan de construcción

No intentaremos modularizar todo el programa al mismo tiempo.

Lo construiremos y probaremos por etapas.

20.1 Etapa 1 — ingresarNotas()

El primer módulo deberá:

  • recibir el arreglo;
  • recibir su tamaño;
  • recorrer las posiciones;
  • solicitar las cinco notas;
  • almacenarlas correctamente.

Cuando funcione:

compila → ejecuta → verifica → continúa.

20.2 Etapa 2 — mostrarNotas()

Ahora separaremos la tarea de mostrar el contenido del arreglo.

Debe producir:

================================
 NOTAS REGISTRADAS
================================
Indice 1 -> ...
Indice 2 -> ...
Indice 3 -> ...
Indice 4 -> ...
Indice 5 -> ...
TipPregunta

¿mostrarNotas() necesita devolver un resultado?

¿O solamente necesita realizar una tarea?

20.3 Etapa 3 — calcularPromedio()

Esta será una función.

Deberá:

  1. recibir el arreglo;
  2. recorrer sus elementos;
  3. calcular la suma;
  4. obtener el promedio;
  5. devolver el resultado.

El main() deberá poder utilizarla así:

promedio = calcularPromedio(notas, TAM);

20.4 Etapa 4 — buscarMayor()

Deberá analizar el arreglo y devolver la nota más alta.

mayor = buscarMayor(notas, TAM);
TipPista

Ya resolvimos este problema en el laboratorio anterior.

No inventes un valor inicial para mayor.

Utiliza un valor que realmente exista dentro del arreglo.

20.5 Etapa 5 — buscarMenor()

Aplicaremos la misma estrategia:

menor = buscarMenor(notas, TAM);

Pregúntate:

¿Qué cambia realmente entre buscar el mayor y buscar el menor?

20.6 Etapa 6 — contarAprobados()

Recuerda nuestra regla:

Aprobado → nota >= 61

La función deberá devolver la cantidad encontrada:

aprobados = contarAprobados(notas, TAM);

20.7 Etapa 7 — contarReprobados()

Ahora aplicaremos:

Reprobado → nota < 61

y guardaremos el resultado:

reprobados = contarReprobados(notas, TAM);

20.8 Etapa 8 — mostrarResultados()

Finalmente construiremos un procedimiento encargado únicamente de presentar:

Promedio
Mayor
Menor
Aprobados
Reprobados

El main() deberá llamarlo enviándole los resultados obtenidos.

27 15. Solución propuesta

💡 Mostrar solución completa 
#include <iostream>
using namespace std;

// Prototipos
void ingresarNotas(int notas[], int TAM);
void mostrarNotas(int notas[], int TAM);
double calcularPromedio(int notas[], int TAM);
int buscarMayor(int notas[], int TAM);
int buscarMenor(int notas[], int TAM);
int contarAprobados(int notas[], int TAM);
int contarReprobados(int notas[], int TAM);
void mostrarResultados(double promedio, int mayor, int menor,
                       int aprobados, int reprobados);

int main()
{
    const int TAM = 5;
    int notas[TAM];

    double promedio = 0;
    int mayor, menor;
    int aprobados = 0;
    int reprobados = 0;

    ingresarNotas(notas, TAM);
    mostrarNotas(notas, TAM);

    promedio = calcularPromedio(notas, TAM);
    mayor = buscarMayor(notas, TAM);
    menor = buscarMenor(notas, TAM);
    aprobados = contarAprobados(notas, TAM);
    reprobados = contarReprobados(notas, TAM);

    mostrarResultados(promedio, mayor, menor,
                      aprobados, reprobados);

    return 0;
}


// ======================================================
// IMPLEMENTACIONES
// ======================================================

void ingresarNotas(int notas[], int TAM)
{
    for (int i = 0; i < TAM; i++)
    {
        cout << "Ingrese nota [" << (i + 1) << "]: ";
        cin >> notas[i];
    }
}


void mostrarNotas(int notas[], int TAM)
{
    cout << "\n================================" << endl;
    cout << " NOTAS REGISTRADAS" << endl;
    cout << "================================" << endl;

    for (int i = 0; i < TAM; i++)
    {
        cout << "Indice " << (i + 1)
             << " -> " << notas[i] << endl;
    }
}


double calcularPromedio(int notas[], int TAM)
{
    int suma = 0;

    for (int i = 0; i < TAM; i++)
    {
        suma = suma + notas[i];
    }

    return suma / static_cast<double>(TAM);
}


int buscarMayor(int notas[], int TAM)
{
    int mayor = notas[0];

    for (int i = 0; i < TAM; i++)
    {
        if (notas[i] > mayor)
            mayor = notas[i];
    }

    return mayor;
}


int buscarMenor(int notas[], int TAM)
{
    int menor = notas[0];

    for (int i = 0; i < TAM; i++)
    {
        if (notas[i] < menor)
            menor = notas[i];
    }

    return menor;
}


int contarAprobados(int notas[], int TAM)
{
    int aprobados = 0;

    for (int i = 0; i < TAM; i++)
    {
        if (notas[i] >= 61)
            aprobados++;
    }

    return aprobados;
}


int contarReprobados(int notas[], int TAM)
{
    int reprobados = 0;

    for (int i = 0; i < TAM; i++)
    {
        if (notas[i] < 61)
            reprobados++;
    }

    return reprobados;
}


void mostrarResultados(double promedio, int mayor, int menor,
                       int aprobados, int reprobados)
{
    cout << "\n================================" << endl;
    cout << " RESULTADOS" << endl;
    cout << "================================" << endl;

    cout << "Promedio..: " << promedio << endl;
    cout << "Mayor.....: " << mayor << endl;
    cout << "Menor.....: " << menor << endl;
    cout << "Aprobaron.: " << aprobados << endl;
    cout << "Reprobaron: " << reprobados << endl;
}

28 16. Analicemos la solución

28.1 Procedimientos

Estos módulos realizan una tarea y utilizan void:

void ingresarNotas(...);
void mostrarNotas(...);
void mostrarResultados(...);

No utilizamos su resultado dentro de una asignación.

28.2 Funciones

Estos módulos procesan información y devuelven un valor:

double calcularPromedio(...);

int buscarMayor(...);
int buscarMenor(...);
int contarAprobados(...);
int contarReprobados(...);

Por eso podemos escribir:

promedio = calcularPromedio(notas, TAM);
mayor = buscarMayor(notas, TAM);

28.3 Parámetros

Varias funciones reciben:

int notas[], int TAM

Esto les permite conocer:

  • los datos que deben procesar;
  • la cantidad de elementos que deben recorrer.

No necesitan depender de variables globales.

29 17. Cierre del laboratorio

Antes teníamos:

Un programa
    ↓
Muchas instrucciones dentro de main()

Ahora tenemos:

             main()
                |
    ---------------------------
    |       |       |         |
 ingresar mostrar calcular   buscar...
 notas    notas   promedio

Cada módulo tiene una responsabilidad.

29.1 Lo más importante de hoy

No aprendimos solamente a escribir funciones.

Aprendimos a dividir una solución en partes pequeñas y comprensibles.

Podemos resumirlo así:

Problema grande
      ↓
Identificar tareas
      ↓
Crear módulos
      ↓
Enviar datos mediante parámetros
      ↓
Devolver resultados cuando sea necesario
      ↓
Construir un main() más claro

Modularizar es organizar la solución, no cambiar el problema.
