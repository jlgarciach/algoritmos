5 Laboratorio 1

5.1 Desarrollo de una solución informática

5.1.1 Objetivo

Aplicar los conocimientos adquiridos durante las primeras clases del curso mediante el análisis, diseño e implementación de una solución informática utilizando pseudocódigo, diagrama de flujo y el lenguaje de programación C++.

ImportanteCompetencias que se evaluarán

Al finalizar este laboratorio el estudiante será capaz de:

  • Analizar un requerimiento.
  • Identificar entradas, procesos y salidas.
  • Diseñar un algoritmo mediante pseudocódigo.
  • Representar la solución utilizando un diagrama de flujo.
  • Implementar el algoritmo en C++.
  • Verificar el funcionamiento de la solución mediante casos de prueba.

6 Requerimiento

Una academia de capacitación desea automatizar el cálculo del promedio de sus estudiantes.

Para ello necesita un programa que solicite la siguiente información:

  • Nombre del estudiante.
  • Primera nota.
  • Segunda nota.
  • Tercera nota.

Posteriormente el sistema deberá:

  1. Calcular el promedio de las tres notas.
  2. Mostrar el promedio obtenido.
  3. Indicar si el estudiante Aprobó o Reprobó.

Considere que:

  • Un estudiante aprueba con un promedio mayor o igual a 61 puntos.
  • En cualquier otro caso el estudiante reprueba.

El programa debe cumplir con todos los requerimientos indicados anteriormente.

TipRecuerde

Utilice únicamente los temas vistos en clase:

  • Variables
  • Entrada de datos (cin)
  • Salida de datos (cout)
  • Operadores aritméticos
  • Operadores relacionales
  • Estructuras de decisión (if / else)

13 Conclusión

Describa brevemente qué aprendió durante el desarrollo del laboratorio.

NotaReflexión

En el desarrollo de software, escribir el código representa únicamente una parte del trabajo.

Antes de programar, un desarrollador debe comprender el requerimiento, analizar la información disponible, diseñar una solución y posteriormente implementarla.

Este laboratorio busca fortalecer esa forma de pensar, la cual será utilizada durante todo el curso.
