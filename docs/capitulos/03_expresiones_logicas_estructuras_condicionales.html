5  Capítulo 3. Expresiones lógicas y estructuras condicionales

5.1 Presentación de la clase

En las clases anteriores aprendimos a identificar entradas, procesos y salidas; declarar variables; utilizar operadores aritméticos; trabajar con DIV y MOD; construir expresiones; y representar una solución mediante pseudocódigo, diagrama de flujo y código C++.

En esta clase daremos continuidad a esos temas incorporando las expresiones lógicas y las estructuras de decisión:

  • if;
  • if...else;
  • if...else if...else;
  • switch...case.

La meta no es memorizar sintaxis. La meta es aprender a decidir qué estructura conviene usar según el problema.

NotaIdea central

Una estructura condicional permite que el algoritmo tome caminos diferentes según el valor de una condición.

7 Repaso rápido: expresiones y operadores

Una expresión es una combinación de variables, constantes y operadores que produce un valor.

int resultado = 3 + 4 * 2;

La multiplicación se evalúa antes que la suma:

3 + 4 * 2
3 + 8

  1. Solicite dos números.

  3. Realice la operación seleccionada.
  4. Evite dividir entre cero.
  5. Muestre un mensaje si la operación no es válida.

9.5 Parte D. Código C++

#include <iostream>
using namespace std;

int main() {
    int num1, num2, resultado;
    char operador;

    cout << "Ingrese el primer numero: ";
    cin >> num1;

    cout << "Ingrese el segundo numero: ";
    cin >> num2;

    cout << "Ingrese la operacion (+, -, *, /, %): ";
    cin >> operador;

    if (operador == '+') {
        resultado = num1 + num2;
        cout << "Resultado: " << resultado << endl;

    } else if (operador == '-') {
        resultado = num1 - num2;
        cout << "Resultado: " << resultado << endl;

    } else if (operador == '*') {
        resultado = num1 * num2;
        cout << "Resultado: " << resultado << endl;

    } else if (operador == '/') {
        if (num2 == 0) {
            cout << "Error: no se puede dividir entre cero." << endl;
        } else {
            resultado = num1 / num2;
            cout << "Resultado: " << resultado << endl;
        }

    } else if (operador == '%') {
        if (num2 == 0) {
            cout << "Error: no se puede obtener residuo entre cero." 
                 << endl;
        } else {
            resultado = num1 % num2;
            cout << "Resultado: " << resultado << endl;
        }

    } else {
        cout << "Operacion no valida." << endl;
    }

    return 0;
}

10 El mismo ejercicio con switch...case

switch es apropiado cuando una misma variable se compara contra valores constantes exactos.

10.1 Sintaxis

switch (expresion) {
    case valor1:
        // instrucciones
        break;

    case valor2:
        // instrucciones
        break;

    default:
        // instrucciones
}

10.2 Código C++

#include <iostream>
using namespace std;

int main() {
    int num1, num2, resultado;
    char operador;

    cout << "Ingrese el primer numero: ";
    cin >> num1;

    cout << "Ingrese el segundo numero: ";
    cin >> num2;

    cout << "Ingrese la operacion (+, -, *, /, %): ";
    cin >> operador;

    switch (operador) {
        case '+':
            resultado = num1 + num2;
            cout << "Resultado: " << resultado << endl;
            break;

        case '-':
            resultado = num1 - num2;
            cout << "Resultado: " << resultado << endl;
            break;

        case '*':
            resultado = num1 * num2;
            cout << "Resultado: " << resultado << endl;
            break;

        case '/':
            if (num2 == 0) {
                cout << "Error: no se puede dividir entre cero." 
                     << endl;
            } else {
                resultado = num1 / num2;
                cout << "Resultado: " << resultado << endl;
            }
            break;

        case '%':
            if (num2 == 0) {
                cout << "Error: no se puede obtener residuo entre cero." 
                     << endl;
            } else {
                resultado = num1 % num2;
                cout << "Resultado: " << resultado << endl;
            }
            break;

        default:
            cout << "Operacion no valida." << endl;
    }

    return 0;
}

11 Comparación entre if y switch

Característica if...else if...else switch...case
Evalúa rangos Sí No directamente
Usa condiciones lógicas Sí No
Compara valores exactos Sí Sí
Claridad en menús Buena Muy buena
Uso recomendado Rangos y condiciones complejas Opciones exactas
ImportanteRegla práctica

Use if cuando la decisión dependa de rangos o expresiones lógicas. Use switch cuando una variable se compare contra opciones exactas.

12 Ejercicio guiado 2: clasificación de edad

12.1 Requerimiento

Crear un programa que:

  1. Solicite el nombre.
  2. Solicite la edad.
  3. No permita una edad igual o menor que cero.
  4. Clasifique:
    • menor de edad: menos de 18;
    • joven adulto: de 18 a 45;
    • adulto: de 46 a 60;
    • adulto mayor: más de 60.
  5. Muestre nombre, edad y clasificación.

12.2 Diagrama de flujo

12.3 Código C++

#include <iostream>
#include <string>
using namespace std;

int main() {
    string nombre;
    string clasificacion;
    int edad;

    cout << "Ingrese su nombre: ";
    getline(cin, nombre);

    cout << "Ingrese su edad: ";
    cin >> edad;

    if (edad <= 0) {
        cout << "Edad invalida." << endl;

    } else if (edad < 18) {
        clasificacion = "Menor de edad";

    } else if (edad <= 45) {
        clasificacion = "Joven adulto";

    } else if (edad <= 60) {
        clasificacion = "Adulto";

    } else {
        clasificacion = "Adulto mayor";
    }

    if (edad > 0) {
        cout << "\nNombre: " << nombre << endl;
        cout << "Edad: " << edad << endl;
        cout << "Clasificacion: " << clasificacion << endl;
    }

    return 0;
}

14 Errores frecuentes

14.1 Usar = en lugar de ==

Incorrecto:

if (opcion = 1)

Correcto:

if (opcion == 1)

14.2 Colocar condición después de else

Incorrecto:

else (edad > 60)

Correcto:

else

14.3 Olvidar break

case 1:
    cout << "Opcion 1";
    break;

14.4 Usar switch para rangos

switch trabaja mejor con valores exactos.

15 Resumen de la clase

En esta clase aprendimos que:

  • Las expresiones lógicas producen valores verdaderos o falsos.
  • La precedencia determina el orden de evaluación.
  • if permite evaluar rangos y condiciones complejas.
  • switch facilita la construcción de menús y opciones exactas.
  • El mismo problema puede resolverse con estructuras diferentes.
  • Una buena solución comienza con análisis y diseño.
  • Los casos de prueba permiten verificar el comportamiento del programa.
