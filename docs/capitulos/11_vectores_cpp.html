13  Vectores en C++

De un arreglo de tamaño fijo a una colección dinámica

14 El reto de hoy

En las últimas clases construimos un Analizador de notas. Primero utilizamos un arreglo tradicional y después modularizamos el programa mediante procedimientos, funciones, parámetros y valores de retorno.

ImportantePregunta para el grupo

¿Qué ocurriría si no sabemos de antemano cuántos estudiantes tendremos?

Hoy pasaremos de un arreglo de tamaño fijo a una estructura que puede crecer durante la ejecución:

vector

15 1. Recordemos el arreglo tradicional

Hasta ahora hemos trabajado con:

const int TAM = 5;
int notas[TAM];
Índice 0 1 2 3 4
Valor 51 85 95 64 100

Ya sabemos que cada dato ocupa una posición, los índices comienzan en 0 y podemos recorrer los elementos con un ciclo.

TipLo que ya sabemos no se pierde

Seguimos trabajando con:

casilla → índice → valor → recorrido → procesamiento

Lo nuevo será administrar una cantidad variable de elementos.

16 2. ¿Por qué necesitamos otra estructura?

Cuando escribimos:

int notas[5];

establecemos desde el principio cinco posiciones.

Pero imaginemos que el programa debe registrar una cantidad de estudiantes que solamente conoceremos durante la ejecución.

Necesitamos una estructura que pueda crecer conforme agregamos datos.

17 3. ¿Qué es vector?

Un vector de C++ almacena elementos del mismo tipo y puede cambiar de tamaño durante la ejecución.

Necesitamos:

#include <vector>

y podemos declarar:

vector<int> notas;

Inicialmente:

notas = [ ]

18 4. Arreglo y vector

ImportanteDiferencia fundamental

El arreglo tradicional parte de un tamaño establecido.

El vector puede crecer o reducirse durante la ejecución.

19 5. push_back(): agregar elementos

vector<int> notas;

notas.push_back(51);
notas.push_back(85);
notas.push_back(95);

Conceptualmente:

Índice     0      1      2
         ┌────┬────┬────┐
Valor    │ 51 │ 85 │ 95 │
         └────┴────┴────┘

Si hacemos:

notas.push_back(64);

64 queda al final.

20 6. size(): conocer la cantidad

cout << notas.size();

Si tenemos cinco elementos:

size() = 5
índices = 0, 1, 2, 3, 4
NotaRecuerda

El tamaño no es el último índice.

El último índice válido es:

size() - 1

21 7. Acceder y recorrer

El acceso sigue siendo conocido:

cout << notas[0];

Y podemos recorrer:

for (int i = 0; i < notas.size(); i++)
{
    cout << notas[i] << endl;
}

Ya no necesitamos TAM: el vector conoce su cantidad de elementos.

22 8. Agregar datos ingresados por el usuario

vector<int> notas;
int cantidad;

cout << "Cuantas notas desea ingresar: ";
cin >> cantidad;

for (int i = 0; i < cantidad; i++)
{
    int nota;

    cout << "Ingrese nota [" << (i + 1) << "]: ";
    cin >> nota;

    notas.push_back(nota);
}

Ahora el mismo programa puede registrar 3, 5, 8 o 20 notas sin cambiar la declaración del vector.

23 9. Primera prueba

#include <iostream>
#include <vector>
using namespace std;

int main()
{
    vector<int> notas;
    int cantidad;

    cout << "Cuantas notas desea ingresar: ";
    cin >> cantidad;

    for (int i = 0; i < cantidad; i++)
    {
        int nota;
        cout << "Ingrese nota [" << (i + 1) << "]: ";
        cin >> nota;
        notas.push_back(nota);
    }

    cout << "\nNotas registradas:" << endl;

    for (int i = 0; i < notas.size(); i++)
    {
        cout << "Indice " << i
             << " -> " << notas[i] << endl;
    }

    return 0;
}
ImportanteProbemos

Ejecuta el programa con 3, luego 5 y finalmente 8 notas.

¿Qué línea del código tuvimos que modificar entre ejecuciones?

Ninguna.

24 10. Regresemos al Analizador de notas modularizado

Nuestro programa anterior tenía conceptualmente:

int main()
{
    const int TAM = 5;
    int notas[TAM];

    ingresarNotas(notas, TAM);
    mostrarNotas(notas, TAM);

    promedio = calcularPromedio(notas, TAM);
    mayor = buscarMayor(notas, TAM);
    menor = buscarMenor(notas, TAM);
    aprobados = contarAprobados(notas, TAM);
    reprobados = contarReprobados(notas, TAM);

    mostrarResultados(promedio, mayor, menor,
                      aprobados, reprobados);
}
Nota¿Tenemos que comenzar nuevamente?

No.

La modularización permite cambiar la forma de almacenar los datos sin destruir toda la solución.

25 11. El arreglo se convierte en vector

Antes:

const int TAM = 5;
int notas[TAM];

Ahora:

vector<int> notas;

26 12. Pasar el vector a una función

ingresarNotas() necesita modificar el vector original agregando elementos:

void ingresarNotas(vector<int>& notas)
Importante¿Qué significa &?

Por ahora leeremos & de esta manera:

La función trabajará con el vector original, no con una copia.

Así, los elementos agregados dentro de la función permanecen disponibles en main().

Más adelante profundizaremos en el paso por referencia.

void ingresarNotas(vector<int>& notas)
{
    int cantidad;

    cout << "Cuantas notas desea ingresar: ";
    cin >> cantidad;

    for (int i = 0; i < cantidad; i++)
    {
        int nota;

        cout << "Ingrese nota [" << (i + 1) << "]: ";
        cin >> nota;

        notas.push_back(nota);
    }
}

27 13. Funciones que solamente consultan

Para una función que no debe modificar las notas utilizaremos:

const vector<int>& notas

Por ahora podemos interpretarlo como:

“Recibe el vector para consultarlo, pero no lo modifica”.

Ejemplo:

void mostrarNotas(const vector<int>& notas)
{
    for (int i = 0; i < notas.size(); i++)
    {
        cout << "Indice " << (i + 1)
             << " -> " << notas[i] << endl;
    }
}

28 14. Transformemos las funciones

28.1 Promedio

double calcularPromedio(const vector<int>& notas)
{
    int suma = 0;

    for (int i = 0; i < notas.size(); i++)
        suma = suma + notas[i];

    return suma / static_cast<double>(notas.size());
}

28.2 Mayor

int buscarMayor(const vector<int>& notas)
{
    int mayor = notas[0];

    for (int i = 1; i < notas.size(); i++)
        if (notas[i] > mayor)
            mayor = notas[i];

    return mayor;
}

28.3 Menor

int buscarMenor(const vector<int>& notas)
{
    int menor = notas[0];

    for (int i = 1; i < notas.size(); i++)
        if (notas[i] < menor)
            menor = notas[i];

    return menor;
}

28.4 Aprobados

int contarAprobados(const vector<int>& notas)
{
    int aprobados = 0;

    for (int i = 0; i < notas.size(); i++)
        if (notas[i] >= 61)
            aprobados++;

    return aprobados;
}

28.5 Reprobados

int contarReprobados(const vector<int>& notas)
{
    int reprobados = 0;

    for (int i = 0; i < notas.size(); i++)
        if (notas[i] < 61)
            reprobados++;

    return reprobados;
}

29 15. El nuevo main()

int main()
{
    vector<int> notas;

    int mayor, menor;

    ingresarNotas(notas);
    mostrarNotas(notas);

    mayor = buscarMayor(notas);
    menor = buscarMenor(notas);

}

29.1 Observa

Antes:

ingresarNotas(notas, TAM);

ingresarNotas(notas);

El vector conoce su tamaño mediante size().

                       int aprobados, int reprobados);

int main()
{

35 21. Tarea para el viernes

35.1 Sistema de registro de temperaturas

Una estación meteorológica necesita registrar una cantidad variable de temperaturas tomadas durante el día.

El programa deberá utilizar:

vector<double>

y estar modularizado mediante funciones y procedimientos.

35.1.1 Requerimientos

El programa deberá:

  1. preguntar cuántas temperaturas se registrarán;
  2. almacenar las temperaturas en un vector<double>;
  3. mostrar todas las temperaturas;
  4. calcular la temperatura promedio;
  5. encontrar la temperatura más alta;
  6. encontrar la temperatura más baja;
  7. contar cuántas temperaturas son mayores que el promedio;
  8. contar cuántas son menores que el promedio;
  9. mostrar todos los resultados.
ImportanteCondición

No se permite colocar toda la lógica dentro de main().

Utiliza como mínimo:

ingresarTemperaturas()
mostrarTemperaturas()
calcularPromedio()
buscarMayor()
buscarMenor()
contarMayoresPromedio()
contarMenoresPromedio()
mostrarResultados()

35.2 Entregables

  1. Análisis de entradas, procesos y salidas.
  2. Código fuente en C++.
  3. Evidencia de dos ejecuciones con diferente cantidad de temperaturas.
  4. Breve explicación de:
    • por qué utilizó un vector;
    • qué funciones retornan valores;
    • qué procedimientos utilizan void;
    • para qué se utilizan los parámetros.

36 22. Cierre

36.1 De tamaño fijo a tamaño dinámico

Con el arreglo aprendimos a trabajar con muchas casillas.

Con las funciones aprendimos a dividir el problema.

Con vector agregamos una nueva capacidad:

la cantidad de datos puede cambiar sin rediseñar el programa.

No buscamos memorizar instrucciones; buscamos aprender a combinar herramientas para construir mejores soluciones.
