14 Diagrama: Sistema de control de parqueos

15 Paso 1

#include <iostream>
#include <string>
using namespace std;

16 Paso 2

//--------------------------------------------------
// Enumeración de los tipos de vehículos
//--------------------------------------------------

enum TipoVehiculo
{
    MOTO = 1,
    CARRO,
    CAMIONETA
};

//--------------------------------------------------
// Declaración de variables
//--------------------------------------------------

// En esta sección declaramos todas las variables que
// utilizaremos durante el programa, aunque algunas
// todavía no se empleen en los pasos siguientes.
// Esto mejora la organización y facilita la lectura
// del código.

string nombreConductor;
string placa;

int tipoVehiculo;
int horas;

double tarifa = 0.0;
double totalPagar = 0.0;

17 Paso 3. Entrada

cout<<"Nombre: ";
getline(cin,nombreConductor);
cout<<"Placa: ";
getline(cin,placa);

cout<<"Horas: ";
cin>>horas;

cout << "Tipo de vehículo" << endl;
cout << "1. Moto" << endl;
cout << "2. Carro" << endl;
cout << "3. Camioneta" << endl;
cout << "\nSeleccione una opción: ";
cin >> tipoVehiculo;

18 Paso 4. Tarifa

switch(tipoVehiculo){
case MOTO: tarifa=10; break;
case CARRO: tarifa=15; break;
case CAMIONETA: tarifa=25; break;
default: tarifa=0;
}

19 Paso 5

totalPagar=tarifa*horas;

cout<<"Total: Q"<<totalPagar<<endl;

23 Paso 7. Mostrando los resultados

Una vez calculado el total a pagar, es momento de presentar la información al usuario de forma clara y ordenada.

//--------------------------------------------------
// Mostrar resultados
//--------------------------------------------------

cout << "\n=========================================\n";
cout << "      SISTEMA DE CONTROL DE PARQUEOS\n";
cout << "=========================================\n\n";

cout << "Conductor : " << nombreConductor << endl;
cout << "Placa     : " << placa << endl;

cout << "Tipo de vehículo" << endl;
cout << "1. Moto" << endl;
cout << "2. Carro" << endl;
cout << "3. Camioneta" << endl;
cout << "\nSeleccione una opción: ";
cin >> tipoVehiculo;


switch(tipoVehiculo)
{
    case MOTO: cout << "Moto"; break;
    case CARRO: cout << "Carro"; break;
    case CAMIONETA: cout << "Camioneta"; break;
}

cout << endl;
cout << "Horas     : " << horas << endl;
cout << "Tarifa    : Q" << tarifa << endl;
cout << "-----------------------------------------" << endl;
cout << "TOTAL A PAGAR : Q" << totalPagar << endl;

25 Paso 8. ¿Cómo podemos mejorarlo?

Nuestro programa funciona correctamente, pero como ocurre en el desarrollo de software real, siempre podemos incorporar nuevas características.

Cada mejora será la oportunidad perfecta para recordar una estructura de control ya estudiada.

Necesidad del programa Concepto que utilizaremos
Validar las horas ingresadas if
Clasificar el tiempo de permanencia if...else
Aplicar descuentos if...else if
Registrar varios vehículos while
Mostrar un menú principal do...while
Mostrar los espacios disponibles for

25.1 Lo que construiremos a continuación

En la siguiente versión del programa incorporaremos:

  1. Validación de datos.
  2. Descuentos según el tiempo de permanencia.
  3. Registro de varios vehículos.
  4. Menú principal.
  5. Visualización de espacios del parqueo.
TipRecuerda

Un buen programador no memoriza estructuras de control.

Las utiliza para resolver problemas reales.
