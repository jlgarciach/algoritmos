Laboratorio: Analizador de notas

TipMeta del laboratorio

En aproximadamente 30 minutos desarrollarás un programa en C++ utilizando un arreglo de 5 notas.

Esta vez el programa no será construido paso a paso por el docente.

La meta es comprobar que ya puedes transformar por tu cuenta la idea:

casilla → índice → valor → recorrido → procesamiento

1. Situación

Un docente necesita un pequeño programa para registrar las notas de 5 estudiantes y obtener información básica del grupo.

El programa deberá almacenar todas las notas en un arreglo y utilizar ciclos para recorrerlo.

ImportantRegla principal

No debes crear variables como:

nota1, nota2, nota3, nota4, nota5

Las cinco notas deben almacenarse en un solo arreglo.

2. Requerimiento

Construye un programa en C++ que permita:

  1. Crear un arreglo para almacenar 5 notas.
  2. Solicitar al usuario las cinco notas.
  3. Mostrar todas las notas almacenadas junto con su índice.
  4. Calcular la suma de las notas.
  5. Calcular el promedio del grupo.
  6. Identificar la nota mayor.
  7. Identificar la nota menor.
  8. Contar cuántos estudiantes aprobaron.
  9. Contar cuántos estudiantes reprobaron.

Considere que:

Aprobado   → nota >= 61
Reprobado  → nota < 61

5. Plan de trabajo sugerido

Etapa 1 — Registrar las notas

Primero consigue que tu programa:

  • declare el arreglo;
  • recorra sus posiciones;
  • solicite las cinco notas;
  • almacene correctamente cada valor.

Cuando funcione, continúa.

Etapa 2 — Mostrar el arreglo

Recorre nuevamente las posiciones y muestra:

Indice 0 -> ...
Indice 1 -> ...
Indice 2 -> ...

Comprueba que los datos coincidan con lo que ingresaste.

Etapa 3 — Suma y promedio

Utiliza los valores almacenados para obtener:

  • suma;
  • promedio.

Etapa 4 — Mayor y menor

Ahora determina:

  • la nota más alta;
  • la nota más baja.
TipUna pista, no la solución

Ya tienes cinco valores almacenados.

Pregúntate:

¿Con qué valor existente del arreglo podría comenzar la variable que guardará el mayor y el menor?

Evita inventar valores arbitrarios.

Etapa 5 — Aprobados y reprobados

Durante el recorrido analiza cada nota:

¿La nota es mayor o igual a 61?

Necesitarás llevar dos contadores.

Solución propuesta

Tip💡 Ver solución

Aquí colocamos la explicación de la solución.

#include <iostream>
using namespace std;

int main() {

    const int TAM = 5;
    int notas[TAM];

    int suma = 0;
    double promedio;

    int aprobados = 0;
    int reprobados = 0;

    // Ingreso de las notas
    for (int i = 0; i < TAM; i++) {
        cout << "Ingrese nota [" << i << "]: ";
        cin >> notas[i];
    }

    // Inicializamos mayor y menor con un valor real del arreglo
    int mayor = notas[0];
    int menor = notas[0];

    // Procesamiento
    for (int i = 0; i < TAM; i++) {

        suma = suma + notas[i];

        if (notas[i] > mayor) {
            mayor = notas[i];
        }

        if (notas[i] < menor) {
            menor = notas[i];
        }

        if (notas[i] >= 61) {
            aprobados++;
        }
        else {
            reprobados++;
        }
    }

    promedio = suma / static_cast<double>(TAM);

    // Mostrar las notas
    cout << "\n================================" << endl;
    cout << "       NOTAS REGISTRADAS" << endl;
    cout << "================================" << endl;

    for (int i = 0; i < TAM; i++) {
        cout << "Indice " << i
             << " -> " << notas[i] << endl;
    }

    // Resultados
    cout << "\n================================" << endl;
    cout << "          RESULTADOS" << endl;
    cout << "================================" << endl;

    cout << "Suma: " << suma << endl;
    cout << "Promedio: " << promedio << endl;
    cout << "Nota mayor: " << mayor << endl;
    cout << "Nota menor: " << menor << endl;
    cout << "Aprobados: " << aprobados << endl;
    cout << "Reprobados: " << reprobados << endl;

    return 0;
}

11. Analicemos la solución

El arreglo

const int TAM = 5;
int notas[TAM];

Tenemos cinco casillas:

notas[0]
notas[1]
notas[2]
notas[3]
notas[4]

El ingreso

for (int i = 0; i < TAM; i++) {
    cin >> notas[i];
}

El mismo cin trabaja cada vez con una posición diferente.

Mayor y menor

int mayor = notas[0];
int menor = notas[0];

En lugar de inventar un valor inicial, utilizamos un dato que sabemos que pertenece al arreglo.

Después comparamos:

if (notas[i] > mayor) {
    mayor = notas[i];
}

y:

if (notas[i] < menor) {
    menor = notas[i];
}

Aprobados y reprobados

if (notas[i] >= 61) {
    aprobados++;
}
else {
    reprobados++;
}

Aquí combinamos tres conocimientos:

arreglos + ciclos + decisiones.

12. Pregunta final

Observa todo el programa.

Tip¿Qué cambió realmente?

Antes necesitábamos pensar en:

nota1
nota2
nota3
nota4
nota5

Ahora pensamos en:

notas[i]

La variable i nos permite trabajar con cualquier posición.

Esa es una de las ideas más importantes de los arreglos.
